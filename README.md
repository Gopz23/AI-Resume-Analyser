# AI Resume Analyzer

AI-powered Resume ATS Analyzer using Python + Gradio.

## Features

- Resume Upload
- ATS Match Score
- Skill Detection
- Missing Skills Detection
- Stylish Dashboard UI

## Technologies

- Python
- Gradio
- Machine Learning
- NLP
- Scikit-learn

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```
